# Hospital

`hr_hospital` is an Odoo 19 module for keeping records of doctors, patients,
diseases, and patient visits.

## Features

- doctors and their supervising doctors;
- patients, attending doctors, and diagnosed diseases;
- patient visits with doctor, disease, diagnosis, and recommendations;
- full access for internal users;
- three master disease records;
- three demo doctors and three demo patients.

## Installation

Add this repository's `custom_addons` directory to `addons_path`, update the
Apps list, and install **Hospital**.
